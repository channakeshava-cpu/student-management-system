# Student Management System API

> Production-ready Spring Boot backend with JWT Authentication, Docker, and MySQL.

## Features

- JWT Authentication
- Role-Based Authorization
- Student CRUD
- Pagination
- Search
- Validation
- Global Exception Handling
- Dockerized Deployment
- Railway Cloud Hosting

## Tech Stack

- Java
- Spring Boot
- Spring Security
- MySQL
- Maven
- Docker

## Run

```bash
docker compose up --build
```
