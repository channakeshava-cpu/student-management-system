# Student Management System API

> Production-ready Spring Boot backend with JWT Authentication, Docker, and MySQL.

## Features

- JWT Authentication
- Role-Based Authorization (ADMIN/USER)
- Student CRUD APIs
- Pagination & Search
- Validation
- Global Exception Handling
- Swagger Documentation
- Docker & Docker Compose

## Tech Stack

- Java
- Spring Boot
- Spring Security
- MySQL
- Maven
- Docker

## Run

```bash
docker compose up --build
```

Swagger:

`http://localhost:8080/swagger-ui/index.html`
